# DevOps Monitoring & Observability

A hands-on DevOps project focused on **application monitoring and observability** using **Spring Boot Actuator, Micrometer, Prometheus, and Grafana**, integrated into a CI/CD workflow.

The project demonstrates how application metrics are exposed, collected, queried, visualized, and monitored through a complete observability pipeline.

---

## 📌 Project Overview

Modern applications need more than just deployment. They need to be **observable** so that engineers can understand application health, performance, resource usage, and runtime behavior.
